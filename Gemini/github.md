# Q1  オープンソースのプロジェクトのソースファイルがGithubに掲載されていません。今、解凍したフォルダにいます。どうgitで自分に登録すればいいですか。
A1 by gemini
解凍したフォルダの中にいる状態（＝ローカルにソースコードがある状態）から、GitHub上のご自身のリポジトリに登録（Push）する手順を分かりやすく解説します。

---

## 全体の流れ

1. **GitHub側で新しいリポジトリを作成**
2. **ローカル（解凍したフォルダ）で `git init` を実行**
3. **ファイルをコミット**
4. **GitHubのURLを設定して送信（Push）**

---

## 具体的な手順

コマンドプロンプトやターミナルで、**解凍したフォルダにいる状態**で以下の手順を実行してください。

### Step 1: GitHubで空のリポジトリを作成する

1. Webブラウザで GitHub にログインします。
2. 画面右上の **「+」** アイコン ➔ **「New repository」** をクリックします。
3. **Repository name** を入力します。
4. ⚠️ **注意点:**
* **「Add a README file」**
* **「Add .gitignore」**
* **「Choose a license」**
* などのチェックボックスはすべて外した状態（チェックなし）で作成してください（空のリポジトリにするため）。


5. **「Create repository」** をクリックします。
6. 作成後に表示されるリポジトリのURL（`[https://github.com/あなたのユーザー名/リポジトリ名.git](https://github.com/あなたのユーザー名/リポジトリ名.git)`）をコピーしておきます。

---

### Step 2: ローカルフォルダでGitを初期化＆追加する

解凍したフォルダのターミナルで、順番にコマンドを実行します。

```bash
# 1. 現在のフォルダをGit管理下に置く
git init

# 2. すべてのファイルをステージング（追加）する
git add .

# 3. 最初のコミットを作成する
git commit -m "Initial commit from unzipped source"

```

---

### Step 3: メインブランチを設定し、GitHubにPush（送信）する

```bash
# 1. デフォルトブランチ名を「main」に変更する
git branch -M main

# 2. 送信先のGitHubリポジトリ（Step 1でコピーしたURL）を登録する
git remote add origin https://github.com/あなたのユーザー名/リポジトリ名.git

# 3. GitHubへコードを送信する
git push -u origin main

```

---

## よくある注意点・トラブル対処

* **オープンソースのライセンス表示（重要）**
* 元のオープンソースプロジェクトに含まれていた **`LICENSE` ファイルや著作権表示（NOTICE等）は消さずにそのまま残して**登録してください。


* **不要なファイルまで登録されそうな場合（ビルド生成物など）**
* `git add .` をする前に、必要に応じて `.gitignore` ファイルを作成し、ビルド後のバイナリや一時ファイルを除外設定しておくとリポジトリが綺麗に保てます。


* **ログインを求められた場合**
* `git push` 時にパスワードを求められた場合、パスワード欄にはアカウントの生のパスワードではなく、GitHubで発行した **Personal Access Token (PAT)** を入力してください。
